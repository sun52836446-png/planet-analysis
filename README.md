# Planet Data Analysis Project

## Project Overview
This project performs a complete data analysis workflow on a real-world exoplanet dataset, including data cleaning, statistical analysis, visualization, and correlation exploration.

## Objectives
- Understand planet discovery trends
- Analyze detection method distribution
- Explore relationships between variables
- Perform correlation analysis

## Tech Stack
Python, Pandas, Matplotlib, Seaborn

## Key Analysis
✔ Data preprocessing  
✔ Missing value handling  
✔ Trend analysis  
✔ Statistical grouping  
✔ Visualization dashboard
